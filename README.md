# Produkteev

Omnichannel CRM for Indonesian SMBs. One inbox for WhatsApp, Instagram, email, and web chat.

## What it does

Produkteev brings all customer conversations into a single dashboard. Sales teams stop switching between apps and start closing deals. Built for the way Indonesian businesses actually work: WhatsApp-first, mobile-friendly, Bahasa Indonesia throughout.

## Features

- **Unified inbox** across WhatsApp, Instagram DM, email, and web chat
- **Contact management** with full conversation history per customer
- **Pipeline tracking** for deals from first touch to close
- **AI-powered replies** using Claude for smart suggestions, auto-categorization, and conversation intelligence
- **Broadcast and campaigns** for bulk WhatsApp messaging with templates
- **Team collaboration** with assignment, internal notes, and SLA tracking
- **Reports and analytics** across channels, agents, and conversion rates

## Tech stack

- **Backend:** Express.js + Node.js
- **Frontend:** React
- **Database:** PostgreSQL
- **WhatsApp:** Baileys gateway
- **AI:** Claude API (conversation intelligence, smart reply, categorization)

## AI capabilities

Produkteev uses Claude for:
- Automatic conversation categorization (complaint, inquiry, order, etc.)
- Smart reply suggestions based on conversation context
- Conversation summaries for handoff between agents
- Sentiment detection on incoming messages
